# Minimalist Flutter Portfolio

A minimalist, single-page developer portfolio built with Flutter Web. Inspired by Claude.ai, this template is designed to be clean, calm, and highly readable, relying entirely on raw Flutter widgets without any third-party UI libraries.

## Features
- **Minimalist Aesthetic:** Neutral warm-white background with near-black text and a muted terracotta accent.
- **Refined Typography:** Utilizes `Fraunces` for large, airy headings and `Inter` for body text.
- **Native Animations:** Smooth scroll and custom fade-in on scroll implemented purely with Flutter `ScrollController` and `AnimatedBuilder`.
- **Responsive:** Scales beautifully across desktop, tablet, and mobile devices.
- **Dark Mode:** Built-in dark mode toggle.

## Running Locally

To run this project on your local machine, use the following command:

```bash
flutter run -d web-server --web-port=8080
```
Then navigate to `http://localhost:8080` in your browser.

## Customization
All the code is centrally located in `lib/main.dart`. You can easily swap out the content, links, and text within the Widget definitions to make it your own!
